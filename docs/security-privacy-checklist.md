# Security / Privacy Checklist

        ## 方針

        個人の作品メモだけをローカル保存し、アカウント連携はMVP外にする

        ## チェック

        - [x] 外部送信をMVP外にした。
        - [x] サンプルに実個人情報を含めない。
        - [x] 手動テストで確認すべき権限を列挙。
        - [x] release asset に手動テスト手順を添付。

        ## Android / Host 権限

        - INTERNET はMVPでは未使用
- 外部ストレージ権限は要求しない

        ## Adobe 公式参照

        - 対象ドメイン docs と created_idea metadata を優先。
