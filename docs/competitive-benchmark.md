# 競合ベンチマーク

        ## 比較対象

        - Backloggd: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- GG App: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Notion: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Google Keep: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。

        ## 採用する基準

        - 入力負荷が低い。
        - 次アクションが明確。
        - ローカルまたは閉域で検証できる。
        - docs と release evidence から状態を追える。

        ## 差別化

        積みゲーム、視聴予定、クリア状況、次に遊ぶ理由を管理する個人カタログに絞り、汎用ノートや大型サービスよりも閉域アルファの検証可能性を優先します。
